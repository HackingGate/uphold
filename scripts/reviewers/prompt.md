You are reviewing one change against a repository's review document.

The document lists constraints. Each has a heading (its title), an id, a
claim, the conditions under which it applies, and questions to ask of a
change. The document also lists static rules that already run; do not report
anything those rules refuse.

Read the change. For each constraint in the document that the change
violates, print the constraint's id or its title, one per line. Print nothing
else: no explanation, no numbering, no punctuation around the name.

If the change violates no constraint in the document, print nothing.

Name a constraint only when the change itself violates it, not when the change
merely touches its subject.
